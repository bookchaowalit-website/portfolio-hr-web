# Nattayaporn Morprakop - Professional Portfolio

A modern, responsive portfolio website for Nattayaporn Morprakop, IT Recruitment Consultant at GetLinks.

## Features

- ✨ Modern design with shadcn/ui components
- 📱 Fully responsive design
- 🎨 Professional color scheme with gradients
- 🔍 SEO optimized with proper metadata
- ⚡ Built with Next.js 15 and TypeScript
- 🎯 Tailwind CSS for styling
- 📧 Contact information prominently displayed
- 💼 Complete professional experience showcase
- 🎓 Education and skills sections
- 📱 Recent professional activity highlights

## Tech Stack

- **Framework:** Next.js 15 with App Router
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **UI Components:** shadcn/ui
- **Icons:** Lucide React
- **Font:** Geist Sans & Geist Mono

## Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn package manager

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

### Development

Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

### Build for Production

```bash
npm run build
npm start
```

## Customization

To customize this portfolio for another HR professional:

1. **Personal Information:** Update the personal details in `src/app/page.tsx`
2. **Experience:** Modify the `experiences` array with relevant work history
3. **Skills:** Update the `skills` array with appropriate competencies
4. **Contact:** Change contact information in both the hero section and contact cards
5. **Metadata:** Update SEO information in `src/app/layout.tsx`
6. **Styling:** Adjust colors and styling in the component classes

## Sections

- **Hero Section:** Name, title, professional summary, and key stats
- **Contact Information:** Phone, email, LinkedIn, and location
- **Professional Experience:** Detailed work history with skills and timeframes
- **Education:** Academic background and achievements
- **Skills:** Professional competencies with experience levels
- **Recent Activity:** Latest recruitment activities and posts
- **Call to Action:** Contact methods and availability
- **Footer:** Professional branding
